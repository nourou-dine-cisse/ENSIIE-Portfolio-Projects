## 📌 Présentation du Projet (Executive Summary)

**En français :**  
Système de Question-Réponse Visuelle (VQA) entraîné sur le dataset VQA v2.0 associant extraction de caractéristiques visuelles par CNN (ResNet), encodage linguistique par LSTM et module de fusion multimodale.

**In English :**  
Multimodal Visual Question Answering architecture on VQA v2.0 dataset fusing deep convolutional image features (ResNet) with LSTM question embeddings.
