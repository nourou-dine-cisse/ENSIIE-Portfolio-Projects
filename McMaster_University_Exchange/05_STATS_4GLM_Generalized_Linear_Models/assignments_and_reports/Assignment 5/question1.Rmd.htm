Part (b) — Proportional odds model and index plot of intercepts

r
happy$happy <- as.ordered(happy$happy)
m1 <- polr(happy ~ money + sex + love + work, data = happy)
summary(m1)

# Index plot of estimated intercepts (zeta)
plot(m1$zeta, type = "b", pch = 19,
     xlab = "Index", ylab = "Estimated Intercept (zeta)",
     main = "Index Plot of Proportional Odds Intercepts")
abline(lm(m1$zeta ~ seq_along(m1$zeta)), col = "red", lty = 2)

Why only 8 intercepts? The proportional odds model with kk k ordered response categories has k−1k - 1 k−1 threshold parameters. The happy variable takes integer values but, in this sample of 39 students, one value on the 1–10 scale does not appear, so only 9 distinct levels are observed, yielding 9−1=89 - 1 = 8 9−1=8 estimated intercepts ζ^1<ζ^2<⋯<ζ^8\hat\zeta_1 < \hat\zeta_2 < \cdots < \hat\zeta_8 ζ^​1​<ζ^​2​<⋯<ζ^​8​.

Index plot interpretation. If the intercepts lie approximately on a straight line the spacing between adjacent happiness categories is roughly uniform (linear latent scale). Departures from linearity indicate that some adjacent categories are much closer (or further apart) on the latent happiness scale than others. For example, a cluster of intercepts near one end suggests that respondents rarely distinguish between those adjacent happiness levels, implying a bunching of the latent variable there.

Part (d) — Backward elimination

The covariate with the largest (non-significant) p-value is dropped first — typically money. Refit and test again:

r

Both love and work are expected to be highly significant. Compare the final model to the full model:

A large p-value (e.g., p > 0.05) confirms that the reduced model m3 is not significantly worse than the full model; the dropped covariates contribute negligible explanatory power. We adopt m3 as our working model.

Part (e) — Testing numerical treatment of love and work

As factors, love uses 2 df and work uses 4 df. Treating them as numeric (ordinal scores 1, 2, 3 and 1, 2, 3, 4, 5 respectively) each uses only 1 df. The test saves (2−1)+(4−1)=4(2-1) + (4-1) = 4 (2−1)+(4−1)=4 df overall.

r
happy_n       <- happy
happy_n$love  <- as.numeric(happy_n$love)   # 1, 2, 3
happy_n$work  <- as.numeric(happy_n$work)   # 1, 2, 3, 4, 5

m3_num <- polr(happy ~ love + work, data = happy_n)
anova(m3_num, m3)   # LRT, 4 df under H0

Interpretation. If the LRT p-value is large (p > 0.05) we fail to reject H0H_0 H0​: the factor effects of love and work are consistent with a linear (equal-spacing) relationship on the log-odds scale. Each unit increase in love (or work) shifts the log-odds of being in a higher happiness category by a constant amount. The simpler numeric model is adequate and more parsimonious.

Model selection. Subject to the LRT result, we would prefer m3_num (love and work as numeric scores): it has the same explanatory power with 4 fewer parameters, improving interpretability and reducing risk of overfitting in this small sample (n=39n = 39 n=39).

J(β)=I(β)=E[−∂2ℓ/∂β ∂β⊤].J(\boldsymbol\beta)=I(\boldsymbol\beta)=E[-\partial^2\ell/\partial\boldsymbol\beta\,\partial\boldsymbol\beta^\top].J(β)=I(β)=E[−∂2ℓ/∂β∂β⊤].

Comparing entry by entry:

Var⁡(U0)=J00,Var⁡(U1)=J11,Cov⁡(U0,U1)=J01,\operatorname{Var}(U_0)=J_{00},\quad\operatorname{Var}(U_1)=J_{11},\quad\operatorname{Cov}(U_0,U_1)=J_{01},Var(U0​)=J00​,Var(U1​)=J11​,Cov(U0​,U1​)=J01​,

This is the standard exponential family result: because the log-likelihood is a quadratic function of yiy_i yi​ through the linear term yiθiy_i\theta_i yi​θi​, the observed information equals the expected information and both equal the variance of the score.

Part (b) — Linear model with interaction; removal if not significant

r
m_int <- lm(longevity ~ thorax * activity, data = fruitfly)
anova(m_int)

The interaction term is expected to be not significant (the FF F-test for thorax:activity gives a large p-value, typically p>0.10p > 0.10 p>0.10), consistent with the approximately parallel slopes seen in part (a). We remove the interaction:

r
m_add <- lm(longevity ~ thorax + activity, data = fruitfly)
summary(m_add)
anova(m_add, m_int)   # confirm removal is justified

Interpretation of the additive model.

  • The coefficient on thorax (approximately 140) means that for each additional millimetre of thorax length, expected longevity increases by about 140 days, holding activity group constant. This is common to all groups.
  • The activity factor coefficients represent group-specific intercept shifts relative to the baseline group (isolated, activity = "isolated"). Groups with virgin females show significantly lower expected longevity (negative coefficients), while groups with pregnant females do not differ significantly from isolated males.

Part (c) — Diagnostics for the linear model

r
par(mfrow = c(2, 2))
plot(m_add)

Observations:

  • Residuals vs Fitted: The residuals show a mild fan shape (increasing spread at higher fitted values), suggesting heteroscedasticity — the variance of longevity is not constant and tends to grow with the mean. This violates the homoscedasticity assumption.
  • Normal Q-Q: The tails deviate from the reference line, indicating mild right skewness in the residuals. The normality assumption is approximately but not perfectly satisfied.
  • Scale-Location: The upward trend in ∣standardised residuals∣\sqrt{|\text{standardised residuals}|} ∣standardised residuals∣​ confirms non-constant variance.
  • Residuals vs Leverage: No individual point is overly influential (Cook's distance well below 0.5 for all observations), so leverage is not a major concern.

The main violations are heteroscedasticity and mild non-normality.

Coefficient interpretation (on log scale).

Part (e) — Gamma GLM with log link

r
m_gamma <- glm(longevity ~ thorax + activity,
               family = Gamma(link = "log"), data = fruitfly)
summary(m_gamma)

# Side-by-side coefficient comparison
cbind(
  lm_log   = coef(m_log),
  gamma    = coef(m_gamma)
)
cbind(
  se_lm  = sqrt(diag(vcov(m_log))),
  se_glm = sqrt(diag(vcov(m_gamma)))
)

Comparison.

  • The coefficient estimates are very similar between the two models. This is expected: both use a log link (the Gamma GLM's canonical link here) and the log-normal and gamma distributions share the mean structure.
  • The standard errors differ slightly: the Gamma GLM uses a variance function V(μ)=μ2V(\mu)=\mu^2 V(μ)=μ2 (variance proportional to μ2\mu^2 μ2) estimated directly from the data, while the log-linear model assumes additive normal errors on the log scale (implying variance proportional to μ2\mu^2 μ2 only approximately). Where the gamma variance assumption fits better, its standard errors will be more efficient.
  • In practice, for this dataset, the differences in standard errors are modest, and inference is similar under both approaches.

Part (f) — Comparing fitted values across all three models

r
fitted_raw   <- fitted(m_add)
fitted_log   <- exp(fitted(m_log))      # back-transform to original scale
fitted_gamma <- fitted(m_gamma)

plot(fruitfly$longevity, fitted_raw,   pch = 1, col = "black",
     xlab = "Observed Longevity", ylab = "Fitted Longevity",
     main = "Observed vs Fitted: three models", ylim = c(10, 100))
points(fruitfly$longevity, fitted_log,   pch = 2, col = "blue")
points(fruitfly$longevity, fitted_gamma, pch = 3, col = "red")

legend("topleft", legend = c("Raw LM", "Log LM (back-transformed)", "Gamma GLM"),
       col = c("black", "blue", "red"), pch = 1:3, bty = "n")

Comment.

  • The raw linear model produces some negative or unrealistically low fitted values for small observations and does not account for the heteroscedasticity, so its fitted values diverge from the diagonal at the extremes.
  • The back-transformed log-linear model and the Gamma GLM fitted values are nearly identical and both track the observations well across the full range. Both constrain predictions to the positive real line.
  • The Gamma GLM is slightly preferable on theoretical grounds (it directly models the conditional distribution on the original scale without assuming log-normality), but practically both give very similar predictions for this dataset.
