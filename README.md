## ⚡ Automated Candidate Application Toolkit

This repository includes a scriptable CLI utility to tailor cover letters, STAR bullet points, and attachments for any target company:

```bash
# Target: AI / LLM / Multi-Agent Research Intern (e.g., Mistral AI, Hugging Face, Google DeepMind)
python3 automate_candidatures.py --profil ai --entreprise "Mistral AI" --poste "Research Engineer Intern — LLM & Agents"

# Target: Quantitative Research / Trading Intern (e.g., BNP Paribas, QRT, Citadel)
python3 automate_candidatures.py --profil quant --entreprise "QRT" --poste "Quantitative Research Intern"

# Target: Data Engineer Intern (e.g., Datadog, Databricks, Snowflake)
python3 automate_candidatures.py --profil de --entreprise "Datadog" --poste "Data Engineer Intern"
```
